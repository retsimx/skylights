# Product Specs

There are no separate product specifications yet. The behaviour contract for
this firmware is:

- `README.md` §2 — wiring and electrical behaviour
- `README.md` §3 — actuation timing and calibrated travel model
- `README.md` §4 — MQTT API
- `README.md` §5 — flashing, OTA and release flow
- `docs/design-docs/` — durable decisions and their limits

Add a spec here when a feature needs user-facing acceptance criteria that do
not belong in the README (for example, a multi-window scheduling feature or a
bench acceptance report). Keep each spec testable and link it from this index.
